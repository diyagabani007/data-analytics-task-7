# SQL Data Extraction & Analysis

## Project Overview

This project demonstrates essential SQL operations for retrieving, combining, and analyzing data from relational databases.

---

## Objectives

- Extract data using SELECT statements
- Perform JOIN operations
- Aggregate data using GROUP BY
- Understand database relationships

---

## SQL Operations Covered

### SELECT
Retrieve records from tables.

### INNER JOIN
Combine related data from multiple tables.

### GROUP BY
Summarize and aggregate information.
